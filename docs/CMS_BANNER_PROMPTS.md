## 🛠️ AI Tool Recommendations

### For Image Generation:
1. **Midjourney** - Best quality, natural results
2. **Leonardo.ai** - Good for specific styles, faster
3. **Adobe Firefly** - Commercial safe, clean results
4. **Canva AI** - Easy templates + AI generation
5. **DALL-E 3** - Good for text rendering

### After Generation:
- **Remove.bg** - Remove backgrounds if needed
- **TinyPNG** - Compress images to <200KB
- **Canva** - Add text overlays if AI text isn't clear
- **Photopea** - Free Photoshop alternative for edits

## 📋 Banner Checklist

Before uploading to CMS, ensure:
- ✅ Image is 1200x400px or 1080x540px
- ✅ File size is under 200KB
- ✅ Text is readable on mobile (test on phone)
- ✅ CTA button is prominent and clear
- ✅ Brand name is visible but not overpowering
- ✅ Colors match festival theme
- ✅ No copyrighted elements used
- ✅ Image quality is sharp (not pixelated)
- ✅ Safe zone respected (60px from edges)
- ✅ File format is PNG or WebP

---

## 💡 Pro Tips

1. **Keep it simple** - Mobile users see smaller version
2. **High contrast** - Text must be readable on all devices
3. **Cultural sensitivity** - Research festival properly
4. **Test on device** - Preview on actual phone before publishing
5. **A/B testing** - Try 2-3 variations to see what works
6. **Update regularly** - Change banners for freshness
7. **Fast loading** - Compress without losing quality
8. **Accessibility** - Ensure sufficient color contrast
9. **Brand consistency** - Use similar style across all banners
10. **Local language** - Consider Hindi/regional text for better connect

4. **Generate** the banner
