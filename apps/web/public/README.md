# Public Assets Folder

Put your static assets (logos, favicons, illustrations) in this folder.

### Files:
- `logo.svg` / `logo.png` - Your brand logo. Available at `/logo.svg` or `/logo.png`.
- `favicon.ico` - Browser tab icon.
- Any other public files placed here will be served at the root URL (e.g. `https://parcelyatrafinal.vercel.app/your-file.png`).
